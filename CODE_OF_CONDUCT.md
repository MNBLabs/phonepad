# Code of conduct

Be decent. Assume the person on the other end is trying to help.

Specifically:

- Criticise code, not people. "This breaks X because Y" is useful; "this is
  terrible" is not.
- Harassment, personal attacks, and demeaning comments about anyone's identity
  are not acceptable and will get you removed.
- English is not everyone's first language. Read generously.
- Nobody is obliged to fix your bug. This is a side project given away for free.

This applies in issues, pull requests, discussions and anywhere else the project
is being discussed.

If someone is behaving badly, report it privately through the contact address in
the repository profile. Reports are handled by the maintainer, who will act on
what seems fair — usually a warning, and a block if it continues. There is no
committee; there is one person reading, and they will try to be reasonable.
