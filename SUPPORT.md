# Support

## Something is not working

Start with **[Troubleshooting](https://phonepad.dynshift.com/troubleshooting/)**.
It covers the things that actually go wrong, in the order they go wrong:

- the PC not showing up in the app
- Windows seeing the pad but the game ignoring it
- pairing failing
- input feeling laggy

If none of that helps, open an issue with the **Bug report** template. The
Diagnostics screen on the phone and the Advanced section of the companion window
have the numbers we will ask for.

## Something is missing

Open an issue with the **Feature request** template. Say what you are trying to
do, not only what you want added — there is often a way already, and if there
is not, knowing the goal shapes the answer.

## Questions

Use Discussions rather than issues. Issues are for things that are broken.

## Supporting the project

PhonePad is free and open source, and stays that way. If it saved you buying a
controller, you can support development:

- **GitHub Sponsors** — see the Sponsor button on this repository
- **Buy Me a Coffee** — linked from [phonepad.dynshift.com/support](https://phonepad.dynshift.com/support/)

Neither unlocks anything. The controller is not going behind a paywall.
